# 求职招聘 App · UI 设计稿展示

把设计稿高保真还原成可交互的网页展示，纯静态、单文件、零依赖。

## 界面

| # | 界面 | 说明 |
|---|---|---|
| 01 | 首页 | 定位栏、搜索框、快捷入口（国企/编制/实习/高薪直招）、推荐职位卡片 |
| 02 | 职位详情 | 急聘标签、公司认证卡、职位描述与任职要求、立即沟通操作栏 |
| 03 | 消息 | 全部/未读/面试约筛选、会话列表、未读角标 |

## 本地查看

直接双击 `index.html`，或：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 新建仓库（例如 `job-app-ui`），把 `index.html` 推到仓库根目录
2. 仓库 **Settings → Pages → Build and deployment**
3. Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`
4. 保存后等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 若希望放在 `docs/` 目录下，则目录选 `/docs`；仓库内无需 `.nojekyll`（纯静态资源）。

## 特性

- 单文件自包含（CSS / JS 全部内联），无需构建、无外部 CDN 依赖
- **并排总览**：三台手机同屏对比展示，适合评审与截图
- **单屏浏览**：一台手机 + 顶部切换，模拟真实 App 浏览动线
- URL hash 深链接：`#home` / `#job` / `#messages` 可直接分享到指定界面
- 响应式：桌面三列并排，平板纵向排列，手机端自适应满屏
